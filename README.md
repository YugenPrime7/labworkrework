## Кратко о проекте
Рекламная веб-страница вымышленных курсов по языку ALGOL 60. 
Страница стилизована под научные публикации и рекламные материалы конца 1950-х - 1960-х годов. 
Цель: показать историческую ценность языка, его академическую строгость и влияние на структурное программирование.
