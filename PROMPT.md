# Роль
Ты - ИИ-агент, верстальщик и дизайнер. Твоя задача - собрать рекламный портал вымышленных курсов "Школа Алгола" на основе подготовленных мной md-файлов.

# Перед сборкой
1. Прочитай research.md, era.md, concept.md.
2. Изучи блоки в папке blocks/.
3. Пойми, что стиль должен быть строгим, академическим, черно-белым, имитирующим печатные издания 1960-х годов.

# Главная задача
Создай index.html. Стиль: минимализм, шрифты с засечками, рамки, отсутствие ярких цветов, ощущение "научного документа".

# Технический результат
- Один файл index.html.
- CSS внутри файла.
- Абсолютные пути к картинкам из assets/.
- Никакого JavaScript, кроме простого (если нужно).
- Текст читаемый, но без современных решений.
